ВмешательствоCV интенсивности, %Доля потока, %
При CV = 0 пациенты моделируются биномиально с фиксированным риском. CV >0 добавляет сценарный общий множитель интенсивности и зависимость между группами. Это не измеренный доверительный интервал. Доля потока — часть потребности, направляемая в эту больницу.
